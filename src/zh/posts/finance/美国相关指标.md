# 美国相关指标

**美国非农**通常指美国劳工统计局（BLS）每月发布的《就业形势报告》里的 **非农就业人数（Nonfarm Payrolls, NFP）**：美国非农业部门当月净增加/减少了多少工作岗位。它排除农业岗位，也不等于“所有就业人数”。

报告通常在每月第一个周五美东 8:30 发布，同时市场会重点看三项：

- 非农就业人数：就业新增是否强劲；
- 失业率：劳动力市场是否变松；
- 平均时薪：工资压力，常被视为通胀线索。

例如，非农和工资都明显高于市场预期，常意味着经济仍热、通胀或难快速回落，市场可能提高对“联储较晚降息/利率更高更久”的预期：美债收益率、美元往往走高，高估值科技股常承压。反过来，适度偏弱的数据通常利好降息预期和成长股；但若弱得像衰退信号，股市也可能下跌，因为企业利润前景恶化。

关键不在数字本身，而在“**实际值相对市场预期**”以及数据组合。例如就业很强但工资降温，未必是利空；就业转弱但消费仍健康，也未必意味着衰退。

## 最值得关注的定期美国数据

|类别|数据|节奏|主要回答什么问题|常见市场含义|
|---|---|---|---|---|
|就业|非农、失业率、平均时薪|每月|就业是否强、工资是否推高通胀|强于预期常推高利率预期；弱于预期通常利率下行|
|就业|初请失业金人数|每周四|最近是否出现裁员上升|持续上升是就业转弱的较早信号|
|就业|JOLTS职位空缺|每月|岗位供需是否紧张|空缺高，偏通胀/偏紧；下降则劳动力市场降温|
|通胀|CPI消费者物价指数|每月|居民端通胀|高于预期常压低美股、抬高收益率，尤其冲击成长股|
|通胀|PPI生产者物价指数|每月|企业端成本压力|可影响对未来CPI和企业利润率的判断|
|通胀|PCE物价指数（核心PCE）|每月|美联储最重视的通胀口径之一|高于预期会削弱降息预期|
|增长|GDP及修正值|每季|整体经济增长速度|强增长有利盈利，但若伴随高通胀，未必利好股市|
|消费|零售销售|每月|居民消费是否有韧性|强于预期利好零售、旅游等，但也可能推迟降息|
|制造业|ISM制造业/服务业PMI|每月|企业景气是在扩张还是收缩|50为荣枯线；服务业对当前美国经济尤其重要|
|房地产|新屋开工、成屋销售、营建许可|每月|利率敏感行业是否走弱|偏弱常反映高利率抑制需求|
|外贸|贸易帐|每月|进出口与外部需求|对GDP预估、美元和特定行业有影响|
|政策|FOMC利率决议、主席发布会、点阵图|一年通常8次|利率实际决定与未来路径|往往是最能直接驱动美股、债券和美元的事件|

美国官方的非农发布时间表显示，它基本按月公布，通常是美东早上 8:30；CPI、PPI等也多在美东早间发布。 [BLS 非农日程](https://www.bls.gov/schedule/news_release/empsit.htm)；GDP、PCE、贸易帐等可在 [BEA 发布日历](https://www.bea.gov/news/schedule) 查询。FOMC一年有八次例会，会议纪要通常在利率决定约三周后公布。 [美联储日历](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm)

可以把对美股的传导理解成两条线：

```
经济数据 → 对通胀/增长的判断
         ├─ 通胀偏高 → 降息预期下降 → 利率/美债收益率上行 → 高估值股票承压
         └─ 增长偏强 → 企业收入利润预期改善 → 周期股、金融等受益

但若“过热”或“衰退”信号太强，以上关系会反转或相互抵消。
```

最实用的看法是：  
**CPI / 核心PCE / 非农工资**看通胀与利率；**非农、初请、JOLTS**看就业；**零售、ISM、GDP**看增长；**FOMC**看政策落地。数据公布时，先比较“实际值—预期—前值”，再看美债收益率和美元的即时反应，通常比只看美股涨跌更能判断市场真正的解读。
