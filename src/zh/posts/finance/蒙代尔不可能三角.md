# 蒙代尔不可能三角（三元悖论）
## 核心结论
一个经济体**无法同时实现下面三项政策目标**，最多三选二，必须放弃其中一项：
1. **资本自由流动**：资金不受管制，可随意跨境流入、流出本国；
2. **固定汇率**：本币汇率盯住某一货币/一篮子货币，汇率稳定不自由波动；
3. **独立货币政策**：本国自主加息、降息，根据自身经济冷热调控利率，不受海外货币政策绑架。

## 三种经典搭配模式
### 模式1：固定汇率 + 资本自由流动 → 放弃货币政策独立性
代表：香港联系汇率制度（盯住美元）、早年东南亚国家
机制：
外资可自由进出，若美国加息，资本会从香港出逃换美元，港币面临贬值压力。为守住固定汇率，香港只能被动跟着加息，哪怕本地经济低迷也不能降息，丧失自主降息刺激经济的能力。

### 模式2：资本自由流动 + 独立货币政策 → 放弃固定汇率（浮动汇率）
代表：美国、欧盟、英国
本国可以自主加息降息调节经济；资本自由跨境流动；汇率任由市场涨跌。
例：美联储降息→美元走弱、资本外流，汇率自动贬值，不需要动用外汇储备维稳汇率。

### 模式3：固定汇率 + 独立货币政策 → 放弃资本自由流动（资本管制）
代表：中国过往阶段
既要自主调节利率管控通胀、经济，又要维持汇率大体稳定，因此设置跨境资本管制，限制大额资金无序进出，隔绝海外利率冲击。

## 通俗理解
把国家比作水池：
- 资本自由流动 = 水池连通全世界水管；
- 固定汇率 = 水池水位必须固定；
- 独立货币政策 = 自己随便控制放水/抽水速度。
水管全开、水位卡死的情况下，自家放水节奏必然被外界水位（海外利率）牵着走，没法自己说了算。

## 现实延伸
1. 我国现状：**有管理的浮动汇率 + 货币政策独立 + 适度资本管制**，并未完全放开资本自由流动，兼顾三者平衡；
2. 欧元区痛点：欧元区各国固定汇率（统一货币欧元）+ 资本完全自由流动，因此各国失去独立货币政策，欧洲央行统一制定利率，导致南北国家经济周期错配（北欧经济过热、南欧衰退却无法单独降息）。
