# 就业、利息和货币通论

1. **核心理论：颠覆传统认知**

- 批判 “萨伊定律”：经济下行时因 “有效需求不足”（大家捂钱不花），供给无法创造需求，易陷入 “生产过剩 - 裁员 - 更不敢消费” 恶性循环；
- 反对降薪自救：工资是购买力，全行业降薪会压缩消费、加重通缩，需政府出手；
- 节俭悖论：个人节俭理性，但全民节俭会导致收入缩水；
- 投资 “动物精神”：决策多靠跟风情绪（选美理论），非精密计算；
- 流动性偏好：危机时现金最安全，利率是放弃安全感的补偿，降息难刺激消费时陷入 “流动性陷阱”。

2. **政策逻辑：政府必出手**经济遇冷时政府会用 “凯恩斯三板斧”（降息、发债、基建）填补需求缺口，资金流向新基建、新能源、民生等领域，普通人可顺势布局。
    
3. **个人策略：顺势而为**

- 防守：收缩非必要开支、储备现金（防失业），避开高端消费 / 房地产等顺周期行业；
- 进攻：抓 “口红效应”（平价娱乐 / 维修 / 二手）、民生刚需（医药 / 养老），或靠技能接单；
- 投资：远离泡沫（大妈聊股时撤），危机时现金抄底优质资产（非杠杆）；
- 职业：优先政府 / 民生相关岗位，或学维修 / 护理等抗周期手艺。

4. **理论边界：非万能神药**凯恩斯主义是 “急救药”，长期用易致滞胀 / 债务 / 泡沫，需结合货币学派（理性预期）、奥地利学派（结构失衡）视角，避免盲从。

视频核心启示：经济下行是财富再分配，普通人需放弃牛市思维，靠 “现金 + 技能 + 顺势布局” 穿越周期，而非焦虑跟风。
