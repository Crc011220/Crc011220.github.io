# Graph RAG

传统 RAG 瓶颈：传统向量检索仅能处理简单单点事实，跨文档多跳推理时易出现线索断裂、注意力稀释问题，底层存在多跳推理断裂、专业实体抽取难、图与向量数据难融合、维护成本高四个核心痛点。

架构核心差异：传统向量 RAG 以文本切片为检索单元，仅能实现 “找得到”，推理过程为黑盒难以复盘；GraphRAG 引入知识图谱，以实体 + 关系 + 切片为检索单元，可直接输出完整逻辑链条，实现 “推得出”。

图谱构建方案：工业界采用分层流水线建图，先用轻量模型粗筛过滤无效切片，再用大模型精准校验补全关系，最后写入图数据库，配套实体对齐、实体消歧、全链路血缘标记机制保障数据合规准确。

检索生成机制：通过智能意图路由器分流 60% 简单问题走向量检索、20% 强关系问题走图检索、仅 20% 复杂问题走双路检索，经重排、序列化转换、思维链约束生成结果，严格区分事实与推测边界。

运维效果验证：采用局部增量更新 + 版本快照回滚机制保障知识时效性，设置 0.85 置信度阈值分流数据，形成人工反哺的质量闭环，视频中的 AB 测试显示 GraphRAG 在跨文档深度推导场景准确率稳定在 80% 以上。
