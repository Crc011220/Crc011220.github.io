# SWIFT（环球银行金融电信协会）

全称：**Society for Worldwide Interbank Financial Telecommunication**，中文叫**环球银行金融电信协会**，大家习惯直接称SWIFT系统。

> ✅ 关键点：**它不是资金清算系统，只是金融报文（指令）传输网络，不实际转账、不保管资金**

## 1. 基本信息

- 成立：1973年，总部**比利时布鲁塞尔**，属于**会员制非营利合作组织**，由全球各大银行共同所有，多国央行参与监督
- 规模：连接全球**11000+**银行、券商、交易所、大型企业，覆盖200多个国家和地区，每天传输数千万条跨境金融报文
- 核心产物：**SWIFT Code（BIC码）**，每家接入银行的唯一身份编码，跨境汇款必须填写，用来识别收款银行

## 2. 工作原理（跨境汇款流程）

1. 你在国内银行发起一笔跨境汇款
2. 国内银行通过SWIFT网络，发送标准化报文（付款指令）给海外收款银行
3. **SWIFT只传递这条消息，钱本身并不走SWIFT**
4. 资金实际划转，依靠各家银行之间预先开立的同业清算账户（代理行账户）完成资金交割

简单类比：SWIFT相当于**国际银行之间的快递系统，只传递“转账通知单”；真正的钱，是银行之间另外结算**。

## 3. 主要用途

- 跨境电汇（个人境外汇款、外贸企业跨境收付款）
- 证券交易、外汇交易的银行间通知
- 信用证、保函等国际贸易金融业务报文传递

## 4. 容易混淆的概念

- SWIFT：**报文通信网络**（传指令）
- CHAPS、Fedwire、CNAPS、CIPS：**清算结算系统**（真正划拨资金）

## 5. 补充：CIPS和SWIFT区别

- SWIFT：全球通用报文通道，欧美主导
- CIPS（人民币跨境支付系统）：中国搭建，用于人民币跨境资金**报文+清算一体化**，可以独立处理人民币跨境业务，也可和SWIFT互通
