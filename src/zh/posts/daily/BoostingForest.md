# 提升森林算法 AUUC
AUUC 是 **Area Under the Uplift Curve（提升曲线下面积）**，用于评估“干预是否真的带来额外效果”。

它与普通 AUC 的核心区别：

|指标|关注的问题|常见场景|
|---|---|---|
|AUC|模型能否区分会发生/不会发生的人|欺诈、流失、是否购买|
|AUUC|模型能否找出“因为干预才发生改变”的人|营销优惠、推送、医疗治疗|

例如发优惠券：

- AUC 模型会找“最可能购买”的人；但他们可能不发券也会买。
- AUUC / uplift 模型会找“发券后购买概率增加最多”的人；这才是优惠券真正该投放的对象。

提升（Uplift）通常写作：

\[ \text{Uplift}(x)=P(Y=1\mid T=1,x)-P(Y=1\mid T=0,x) \]

其中 \(T=1\) 是接受干预（如发券），\(T=0\) 是对照组。

“提升森林算法”一般指 **Uplift Random Forest / Causal Forest**：它类似随机森林，但分裂节点时不只追求预测购买率更准，而是追求把不同“干预增量效果”的人群分开。最终可按预测 uplift 排序，把资源优先给高 uplift 人群。

一句话：

- **AUC：谁最可能转化？**
- **AUUC：对谁采取行动最值得、最能改变结果？**
- **提升森林：用树模型学习这种“行动带来的增量效果”。**
