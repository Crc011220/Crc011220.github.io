# DeepSeek Harness
DeepSeek Harness 的插件化全流程理念，是其区别于同类 AI 框架的核心竞争力。

与 LangChain 的差异：以餐厅运营类比，LangChain 仅聚焦出菜这类核心工作流，需搭配前端、数据库等其他工具完成系统搭建；DeepSeek Harness 则覆盖从前端到后台的全流程，类似 Next.js 对比 React，开发更便捷。

与 Cloud Code 的差异：Cloud Code 是成熟的 AI 应用成品，DeepSeek Harness 则是可自定义的 AI 应用研发平台，通过插件系统覆盖从框架搭建到功能实现的全环节，用户可按需替换插件打造不同定位的 AI 应用。

核心优势：内置 UI 界面、上下文管理、大模型运行时等默认模块，开发 AI 应用仅需修改插件和配置知识库，大幅减少从零搭建的工作量；目标是打造类似 npm 的插件生态，吸引全球开发者贡献插件。

当前状态：目前仅发布 0.1 版本，插件体系尚未成熟，建议观望至 1.0 版本及生态完善后再学习。

现阶段了解 DeepSeek Harness，可作为技术面试的差异化展示内容。
